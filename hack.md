## The Theme: Attestcoin Protocol
*The Attestcoin Protocol was previously introduced under the name Universal Smart Contracts (USC).*

> "Every submission this season must leverage the Attestcoin Protocol.
> The Attestcoin Protocol extends Creditcoin with decentralized infrastructure for verified cross-chain data and messaging. It enables applications on Creditcoin to use attested data from other blockchains and execute cross-chain business logic without relying on centralized oracle operators.
> Show how your project meaningfully integrates the Attestcoin Protocol, whether through trustless cross-chain DeFi, tokenized real-world assets, gaming economies, or verifiable governance."

## Rules & Submission Requirements

### Mandatory Attestcoin Protocol Integration
- Working Attestcoin Protocol integration code running within your project.
- Technical documentation detailing your setup and explaining how the project uses the Attestcoin Protocol.
- **Core Scoring Criterion:** *"Depth of Attestcoin Protocol utilization will be evaluated as one of the core scoring criteria."*

### Submission Form Requirements
1. Project Name
2. Project Logo (PNG, SVG, or AI)
3. Project Sector (e.g. RWA)
4. Project Description
5. Attestcoin Protocol Integration Summary (explain how project uses Attestcoin / USC)
6. GitHub Repository URL (must include a README)
7. Project Deck or Whitepaper (PDF URL)
8. Prototype Demo Video URL (120-second standard)

### Project Requirements
- Must be original work created during the hackathon.
- Must be deployed on a testnet (Creditcoin CC3 Testnet).
- Must integrate the Attestcoin Protocol as a core feature.
- Must respect third-party IP.
